# 4 — SQL injection via FromSqlRaw interpolation

**The vuln:** it *looks* safe because it's EF Core — but `FromSqlRaw` with an interpolated
string interpolates in C# **before** EF sees it, so it's not parameterized:
```csharp
db.Orders.FromSqlRaw($"SELECT * FROM Orders WHERE Ref = '{userRef}'")   // concatenation in disguise
```
The compiler even warns (EF1002).

**The exploit:** same as challenge 1, 5 columns this time.
```
ref = ' UNION SELECT 1,1,1,1,Secret FROM Flags --     → flag in the ref column
```

**The fix:** use a method that parameterizes the interpolation — `FromSql` (not `FromSqlRaw`)
or `FromSqlInterpolated`, or plain LINQ:
```csharp
db.Orders.FromSql($"SELECT * FROM Orders WHERE Ref = {userRef}")   // {userRef} → DbParameter
db.Orders.Where(o => o.Ref == userRef)
```

**The lesson:** `FromSqlRaw` ≠ `FromSql`. Same-looking code, opposite safety. Know which EF
methods parameterize.
