# W2 — Encoding chain

**The setup:** a string that's been through several encoding layers. None of them are
encryption — there's no key.

**How to solve it:** peel the layers in reverse (the flag was encoded flag → ROT13 → hex →
base64).
```bash
echo '<payload>' | base64 -d | xxd -r -p    # base64, then hex -> bytes
# then apply ROT13:  ... | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```
The decoy decodes in one step to `flag{not_this_layer}` — a reminder to finish the chain.

**The lesson:** encoding is not encryption. base64/hex/ROT13 hide nothing from anyone; never
treat encoded data as protected.
