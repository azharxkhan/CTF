# W4 — Hidden in a file

**The setup:** two recovered files. One hides the flag as an embedded string; the other is
not the type its extension claims.

**How to solve it:** check what each file really is, then pull the string.
```bash
file *                              # photo.dat is actually a PNG (renamed)
strings telemetry.bin | grep flag   # the flag is an embedded string
exiftool <image>                    # metadata (EXIF comments) also leak secrets
```

**The lesson:** file extensions lie — check the real type with `file`. Metadata and embedded
strings leak secrets; strip them before shipping files, and never trust a name.
