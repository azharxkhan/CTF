# 7 — Path traversal

**The vuln:** the report download joins your filename onto the reports directory with no
validation:
```csharp
var path = Path.Combine(reportsDir, userFilename);      // "../flag.txt" escapes the folder
return File(File.ReadAllBytes(path), ...);
```

**The exploit:** climb out of the reports folder.
```bash
curl -s -G --data-urlencode "file=../flag.txt" http://<host>:5003/api/reports/download
# ../../ etc. reach further; absolute paths work too
```

**The fix:** resolve the full path and confirm it stays inside the allowed root.
```csharp
var root = Path.GetFullPath(reportsDir);
var requested = Path.GetFullPath(Path.Combine(root, file));
if (!requested.StartsWith(root + Path.DirectorySeparatorChar)) return Results.BadRequest();
```

**The lesson:** never trust a filename. Canonicalize and confine to the intended directory —
a single `..` strip isn't enough (`....//` survives it).
