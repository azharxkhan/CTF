# 10 — Blind (time-based) SQL injection

**The vuln:** the status check is injectable, but returns an identical response every time —
no data comes back. The query is still concatenated, so you can inject a `WAITFOR DELAY`.

**The exploit:** use response *time* as a yes/no oracle, and extract the secret char by char.
```
ref = x'; IF(1=1) WAITFOR DELAY '0:0:3' --      → ~3s (oracle confirmed)
ref = x'; IF (SUBSTRING((SELECT TOP 1 Secret FROM Flags),<pos>,1)='<ch>') WAITFOR DELAY '0:0:2' --
```
Script the loop over positions × characters (bash/python), or `sqlmap --technique=T`.

**The fix:** parameterize — same as any injection.
```csharp
var sql = "SELECT Id FROM Orders WHERE Ref = @ref";
cmd.Parameters.AddWithValue("@ref", r);   // an injected WAITFOR is now just text
```

**The lesson:** "no visible output" is not "safe". Any observable difference — even response
time — leaks data one bit at a time.
