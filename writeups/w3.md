# W3 — Weak hash

**The setup:** two leaked password hashes. One is an unsalted MD5; the other is bcrypt.

**How to solve it:** identify the types, crack the weak one, submit the plaintext.
```bash
hashid <hash>
john --format=raw-md5 --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
john --show hashes.txt              # the cracked plaintext -> submit it
```
The bcrypt hash is a decoy: slow by design, it won't fall to a laptop wordlist run.

**The lesson:** a hash isn't reversible — cracking is guessing plaintext and hashing until it
matches. Unsalted MD5 falls instantly; use a slow, salted hash (bcrypt/argon2) so it doesn't.
Not every hash is meant to be cracked.
