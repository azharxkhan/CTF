# Write-ups

One write-up per challenge — the vuln, how it's exploited, the secure fix, and the one-line
lesson. **Publish each on solve** (CTFd unlock-on-solve, or link from the field manual /
player host after a challenge is retired). They contain no flag values.

The secure code shown here mirrors the reviewer answer keys (`*.patched.cs.txt`) — so a player
who read the write-up already knows what the patch flag wants.

| Challenge | File |
|-----------|------|
| W1–W4 warm-ups | `w1.md` … `w4.md` |
| 1–12 main board | `c1.md` … `c12.md` |
