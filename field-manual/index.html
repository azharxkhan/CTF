Field Manual

You're working inside the CTF environment. It has everything you need and no internet — that's deliberate. Read the source, break the app, then fix it: the patch flag is worth 50% more than the exploit flag.

Flag format

Every flag looks like flag{lowercase_words}. Submit on the scoreboard. Submission is rate-limited (~10/min) — no brute forcing.

The toolkit (already installed)

nmap -sV <host>        # find services + versions (W1)
curl / jq              # poke API endpoints
john / hashid / hashcat + rockyou.txt   # crack hashes (W3, C8)
jwt_tool               # inspect / crack / forge JWTs (C8, C9)
git log --all / git show <commit>        # dig through history (C3)
file / strings / exiftool               # pull secrets out of files (W4)

How scoring works

  • Exploit flag — for breaking the challenge.
  • Patch flag (+50%) — submit a working fix diff; a reviewer checks it. You'll be asked to briefly explain your solve first.
  • Dynamic scoring: hard challenges are worth more as fewer people solve them.

Hints

Each challenge has a three-step hint ladder (where to look → what technique → how to apply). Each costs points and unlocks over time.
